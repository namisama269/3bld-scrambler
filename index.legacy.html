Custom Letter Scheme & Encoding Order Guide

A letter scheme is a 48-character string that maps letters to cube stickers for BLD memorization. The encoding order (20 chars) is set separately in the Order field below.

Structure
  • Characters 1-24: Corners — 8 corners × 3 orientations = 24 letters
  • Characters 25-48: Edges — 12 edges × 2 orientations = 24 letters
  • Total: 48 letters, space-separated by piece

Corner order: UFR UFL UBL UBR DFR DFL DBL DBR
Edge order: UR UF UL UB DR DF DL DB FR FL BL BR

Encoding Order Format

The encoding order is a 20-letter string (8 corner letters + 12 edge letters) that controls cycle-break priority. Each letter is the first sticker letter of a piece in your current scheme. Earlier position = higher priority.

  • Letters 1-8: Corner break-in priority. In Speffz: C=UFR, D=UFL, A=UBL, B=UBR, V=DFR, U=DFL, X=DBL, W=DBR
  • Letters 9-20: Edge break-in priority. In Speffz: B=UR, C=UF, D=UL, A=UB, V=DR, U=DF, X=DL, W=DB, J=FR, L=FL, R=BL, T=BR

Default OrdUDE = CDABVUXW BCDAVUXWJLRT (U>D>E layer order, shown in Speffz letters).

Example: To prioritize breaking into DBR (W) before UFR (C) for corners: WDABVUXC BCDAVUXWJLRT.
